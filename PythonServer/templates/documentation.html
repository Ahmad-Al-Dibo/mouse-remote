📋 Overview

The Mouse Remote Control API is a Flask-based REST service that allows you to programmatically control your mouse. Send HTTP requests to:

  • Get current mouse position
  • Click at specific coordinates
  • Move the mouse by offsets
  • Execute automated click patterns
  • Reset mouse to default position

Base URL: http://localhost:5000/api

✨ Key Features

🎯 Precision Control

Exact pixel-level mouse positioning and clicking

⚡ Fast Response

Minimal latency for real-time control

🔒 Safe

Built-in failsafe and boundary protection

🔄 Automation

Support for complex click patterns and sequences

🔌 API Endpoints

GET /api

Description: Get list of all available endpoints

Response:

{
  "message": "Welkom bij de Click Automation API!",
  "endpoints": {
    "/coordinates (GET)": "Get current mouse coordinates",
    "/reset (POST)": "Reset mouse to (10, 10)",
    "/click (POST)": "Click at specified coordinates",
    "/move (POST)": "Move mouse by offset",
    "/click_pattern (POST)": "Execute click pattern",
    "/documentation": "View documentation"
  }
}
GET /api/coordinates

Description: Get the current mouse position

Example Request:

GET http://localhost:5000/api/coordinates

Response:

{
  "x": 1024,
  "y": 768
}
POST /api/click

Description: Click at specified coordinates

Parameter Type Description
x Required Integer X coordinate
y Required Integer Y coordinate

Example Request:

curl -X POST http://localhost:5000/api/click \
  -H "Content-Type: application/json" \
  -d '{"x": 500, "y": 300}'

Success Response:

{ "status": "success" }

Error Response:

{ 
  "status": "error", 
  "message": "x and y are required" 
}
POST /api/reset

Description: Reset mouse position to (10, 10)

Example Request:

POST http://localhost:5000/api/reset

Response:

{ "status": "success" }
POST /api/move

Description: Move mouse by offset values

Parameter Type Default Description
add_x Optional Integer 0 X offset (positive = right)
add_y Optional Integer 0 Y offset (positive = down)

Example Request:

curl -X POST http://localhost:5000/api/move \
  -H "Content-Type: application/json" \
  -d '{"add_x": 50, "add_y": -30}'

Response:

{
  "x": 1074,
  "y": 738
}
POST /api/click_pattern

Description: Execute a series of automated clicks with custom timing

Parameter Type Default Description
positions Optional Array [[10, 10]] List of [x, y] coordinates
repeat Optional Integer 1 Times to repeat pattern
delay Optional Float 60 Seconds between repeats
sleep_time Optional Float 0.5 Seconds between clicks
automationEnabled Optional Boolean true Enable/disable automation

Example Request:

curl -X POST http://localhost:5000/api/click_pattern \
  -H "Content-Type: application/json" \
  -d '{
    "positions": [[100, 100], [200, 200], [300, 300]],
    "repeat": 3,
    "delay": 60,
    "sleep_time": 0.5,
    "automationEnabled": true
  }'

Response:

{ "status": "success" }

⚛️ React Integration

Custom Hook - useMouseRemote

{% raw %}import { useState, useCallback } from 'react';

const API_BASE = 'http://localhost:5000/api';

export const useMouseRemote = () => {
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const getCoordinates = useCallback(async () => {
    setLoading(true);
    try {
      const res = await fetch(`${API_BASE}/coordinates`);
      return await res.json();
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }, []);

  const click = useCallback(async (x, y) => {
    setLoading(true);
    try {
      const res = await fetch(`${API_BASE}/click`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ x, y })
      });
      return await res.json();
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }, []);

  const executePattern = useCallback(async (pattern) => {
    setLoading(true);
    try {
      const res = await fetch(`${API_BASE}/click_pattern`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(pattern)
      });
      return await res.json();
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }, []);

  return { getCoordinates, click, executePattern, loading, error };
};{% endraw %}

🔧 Troubleshooting

Connection Refused

  • Ensure Python server is running: python cli.py
  • Check if running on port 5000
  • Try http://localhost:5000/api in browser

CORS Errors

  • Install Flask-CORS: pip install flask-cors
  • Add to server: 
    from flask_cors import CORS
app = Flask(__name__)
CORS(app)

Mouse Not Responding

  • Move mouse to screen corner to trigger failsafe
  • Check for permission errors
  • Restart Python server

Invalid JSON Response

  • Ensure Content-Type header is application/json
  • Validate JSON format in request body
  • Check server console for error messages
